# 🎓 Ага — Приложение для изучения английского

Интерактивное веб-приложение для практики английского языка с различными режимами обучения.

## 📱 Возможности

### 💬 Режим "Свободный разговор"
- Общение на английском языке
- Автоматический перевод фраз
- Функция прослушивания с синтезом речи
- Ввод текста или использование микрофона

### 🎤 Режим "Тренировка"
- Практика фиксированных фраз
- Отслеживание прогресса (XP система)
- Проверка произношения через микрофон
- Полезные фразы для начинающих

### 😂 Генератор шуток
- Загрузка случайных шуток на английском
- Различные категории (General, Programming, Knock-Knock)
- Синтез речи для прослушивания
- Копирование шуток в буфер обмена

## 🚀 Быстрый старт

### 1. Включение GitHub Pages

1. Откройте [Settings репозитория](https://github.com/nmurtazin/aga/settings)
2. Перейдите в **Pages** (в левом меню)
3. В разделе "Build and deployment":
   - **Source**: выберите "Deploy from a branch"
   - **Branch**: выберите "main" и папку "/ (root)"
   - Нажмите **Save**
4. Ждите 1-2 минуты, пока GitHub разместит приложение

### 2. Доступ к приложению

Ваше приложение будет доступно по ссылке:
```
https://nmurtazin.github.io/aga/
```

## 🛠 Технологический стек

- **HTML5** — структура приложения
- **CSS3** — стилизация и адаптивный дизайн
- **JavaScript (Vanilla)** — интерактивность
- **Web Speech API** — синтез и распознавание речи
- **Joke API** — загрузка шуток (для генератора)

## 🎯 Основные функции

### Свободный разговор (`index.html`)
- Интерфейс, похожий на мессенджер
- Два режима: чат и тренировка
- Мобильная оптимизация
- Поддержка микрофона

### Генератор шуток (`joke-generator.html`)
- Случайные шутки через API
- Категории шуток
- Копирование в буфер обмена
- Счетчик загруженных шуток
